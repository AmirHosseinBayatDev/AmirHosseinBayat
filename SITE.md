# Site brief

This is the personal website of **AmirHossein Bayat** (امیرحسین بیات), a web developer. It starts as a hold page and will later become the main portfolio.

## Purpose

A personal portfolio. The audience is AmirHossein: a place to present web-development work, ideas, and experience.

## Current phase: Coming Soon

The live site is a **Persian** Coming Soon hold page. It is not collecting emails. It shows:

- A Coming Soon headline and description
- A profile card (name, photo, role, bio)
- Instagram, Telegram, and GitHub links

## Future evolution

1. **Coming Soon (now)** — Persian hold page. Colors, layout, and visual design stay as they are, aside from copy and identity the owner asks to change.
2. **Full portfolio** — the main site. Bilingual: Persian and English. Showcase web-development work.
3. Later additions (projects, writing, contact) should grow out of this same personal site, not a separate brand.

Custom fonts are Vazirmatn for body copy and El Messiri for headings.

The footer credit is in English: `© 2026 AmirHossein Bayat`.

## Stack
